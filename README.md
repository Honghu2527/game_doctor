# 医学生养成记录 / Med Student Life Sim

一个面向中国医学教育与职业路径的分支剧情人生模拟器。

> 从临床医学入学、白大褂宣誓、基础医学、见习、考研/读研、规培、夜班、医患沟通，一路走到主治、副高、主任、临床专家甚至院士。每个选择都会改变属性，也可能影响多年后的结局。

## 当前版本：v0.3

- 互动高考抽分：点击开始 / 停止，750 分制
- 游戏化高考分段与 32 个医学院校选项
- 院校压力、科研/临床倾向与开局属性修正
- 可视化录取通知书
- 三档人生难度：温和 / 真实 / 地狱
- 六项属性：知识、体力、心理、金钱、科研、声望
- 25 个主线节点 + 17 个随机/支线事件
- 分支剧情、前置条件与隐藏 Flag
- 概率事件
- 多种职业结局
- 人生记录日志
- 浏览器本地自动存档 / 继续上次人生
- 手机 / 桌面响应式
- 零依赖 Vanilla HTML / CSS / JavaScript
- 可直接通过 GitHub Pages 从 `main` 分支根目录发布

## 当前剧情范围

临床医学入学 → 白大褂宣誓 → 解剖考试 → 实验室选择 → 临床见习 → 毕业分流 → 硕士/规培 → 第一篇论文 → 夜班 → 医患冲突 → 主治阶段 → 副高评审 → 主任/专家/科研路线 → 人生结局

## 在线发布（GitHub Pages）

本项目是纯静态站点，不需要自定义构建流程。

在 GitHub 仓库中打开：

`Settings → Pages → Build and deployment`

选择：

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/(root)`

点击 `Save`。

发布地址：

`https://honghu2527.github.io/game_doctor/`

以后只要 `main` 分支更新，GitHub Pages 会自动重新发布。

## 本地运行

直接打开 `index.html` 即可。

## v0.3：院校生态系统

学校现在不再只是属性加成，而会改变实际玩法：

- 6 类培养生态：科研密集型、顶级临床平台型、交叉创新型、强势医科大学型、区域临床强校型、逆风成长型
- 32 所学校均有独立的专属开局事件
- 每类学校有不同的机会事件池与触发概率
- 主线节点会出现不同的院校专属选项
- 入学时生成 6 项个人天赋：记忆力、抗压、沟通、动手、科研直觉、英语
- 天赋会参与后续成功概率和条件判定
- 高资源学校拥有更多机会，但同时承担更高竞争与压力
- 区域/地方院校拥有资源争取、基层实践、考研跃迁等不同路线

培养生态均为游戏化抽象，不代表现实高校官方培养方案或价值排名。


## v0.4：真正的分流人生树

- 不同院校生态从大学第一题开始进入不同剧情
- 32 所学校仍保留各自独立院校专属事件
- 新增醒目的“关键人生选择”提示
- 本科阶段可分为科研、临床、均衡、国际四条主线
- 本科毕业后可走推免、考研、直接就业规培、海外升学
- 推免后可选临床专硕、学硕、直博
- 考研失败可二战或直接就业
- 硕士后可选国内博士、海外博士或不读博
- 博士阶段包含课题危机、联合培养、国际会议、重点项目与毕业去向
- 临床路线包含规培、夜班、结业考试、第一份工作、主治与高级职称
- 新增 3 轮“只能申请一个”的竞争机会池：本科、研究生、博士/青年医生
- 申请结果由属性、天赋和随机性共同决定，成功/失败会留下不同 Flag 并改变后续路线


## v0.5.1：本科 + 医学专科双层级

- 院校数据扩展到 92 所：74 所本科、18 所医学专科
- 择校页支持学校/城市搜索，以及本科/专科筛选
- 低分段不再直接失去医学路线，可进入医学专科三年制路径
- 医学专科拥有独立剧情：技能实训、优质实习、基层实践、专升本、就业与后续继续教育
- 专升本成功后可重新进入本科毕业分流，再继续考研、硕士和博士路线
- 专科阶段也有“只能申请一个”的竞争机会池，并使用多步骤申请流程
- 结局新增生涯档案：起点、学历路径、最终路线、关键机会
- 任意结局后可以写“给下一位医学生的一句话”
- 当前 GitHub Pages 留言墙使用浏览器本地存储；未来微信小程序版将切换为云端共享留言墙

所有高考门槛均为游戏化数值，不是实际录取线；具体招生专业、升学政策和职业资格要求以当年官方规定为准。


## v0.6：出生档案 + 更宽高考分布

开局新增 5 个出生条件：
- 成长环境：超大城市 / 省会强二线 / 地级市 / 县城 / 乡镇农村
- 是否独生子女
- 家庭经济：紧张 / 普通 / 宽裕 / 优越
- 家庭教育资源
- 医学家庭背景

这些条件只影响游戏资源、信息差、经济压力、家庭支持与少量高考分布修正，不代表现实群体的能力或价值。

高考抽分扩展到约 280–745 的游戏范围，并使用分层随机分布。

院校层级规则：
- 530 分及以上：只开放本科医学路线
- 450–529：本科冲刺 + 医学专科并存
- 280–449：只开放医学专科路线
- 600+ 及更高分数不会再显示专科院校

当前学校池：
- 74 所本科
- 18 所真实医学专科 / 高职
- 3 所低分段游戏虚拟医学高职
- 合计 95 所

所有门槛均为游戏化数值，不是现实录取线。

## v0.8：动态人生进度 + 研究生择科 + 科室分支

- 顶部不再使用固定的“出生→高考→医学院→升学→规培”假流程
- 改为根据当前人生状态实时生成“当前阶段 + 下一阶段候选”
- 临床专硕显示为“专硕 + 并轨规培”，不会毕业后重复从规培第一年开始
- 学硕阶段先走科研训练；如毕业后回临床，再进入规培
- 本科考研失败或不读研，可直接择科后进入规培
- 直博先选学科方向，但不视为完成规培
- 研究生录取后增加科室 / 学科方向选择
- 首批 14 个方向：内科、外科、儿科、妇产、急诊、麻醉、医学影像、核医学、病理、精神科、全科、肿瘤、眼科、皮肤科
- 每个方向拥有独立的训练压力、夜班、科研、操作与生活节奏参数
- 每个方向拥有专属开局事件和后续事件池
- 科室压力参数会真实参与后续负面属性消耗
- 当前科室会写入顶部角色档案和最终生涯档案
- 视觉上重新提高角色档案区域的文字对比度，并强化动态阶段与科室卡片

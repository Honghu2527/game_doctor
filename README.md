# 医学生养成记录 / Med Student Life Sim

一个面向中国医学教育与职业路径的分支剧情人生模拟器。

> 从临床医学入学、白大褂宣誓、基础医学、见习、考研/读研、规培、夜班、医患沟通，一路走到主治、副高、主任、临床专家甚至院士。每个选择都会改变属性，也可能影响多年后的结局。

## 当前版本：v0.3

- 互动高考抽分：点击开始 / 停止，750 分制
- 游戏化高考分段与 32 个医学院校选项
- 院校压力、科研/临床倾向与开局属性修正
- 可视化录取通知书
- 三档人生难度：温和 / 真实 / 地狱
- 六项属性：知识、体力、心理、金钱、科研、声望
- 25 个主线节点 + 17 个随机/支线事件
- 分支剧情、前置条件与隐藏 Flag
- 概率事件
- 多种职业结局
- 人生记录日志
- 浏览器本地自动存档 / 继续上次人生
- 手机 / 桌面响应式
- 零依赖 Vanilla HTML / CSS / JavaScript
- 可直接通过 GitHub Pages 从 `main` 分支根目录发布

## 当前剧情范围

临床医学入学 → 白大褂宣誓 → 解剖考试 → 实验室选择 → 临床见习 → 毕业分流 → 硕士/规培 → 第一篇论文 → 夜班 → 医患冲突 → 主治阶段 → 副高评审 → 主任/专家/科研路线 → 人生结局

## 在线发布（GitHub Pages）

本项目是纯静态站点，不需要自定义构建流程。

在 GitHub 仓库中打开：

`Settings → Pages → Build and deployment`

选择：

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/(root)`

点击 `Save`。

发布地址：

`https://honghu2527.github.io/game_doctor/`

以后只要 `main` 分支更新，GitHub Pages 会自动重新发布。

## 本地运行

直接打开 `index.html` 即可。

也可以在项目目录启动任意静态服务器，例如：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## v0.2 架构

- `data/schools.js`：高考区间与学校数据
- `data/events.js`：主线与随机支线剧情
- `app.js`：纯 JavaScript 状态机与存档
- `docs/MINIPROGRAM_PLAN.md`：微信小程序迁移方案

高考分数与院校门槛均为游戏机制，不代表真实录取线。正式真实志愿模块需要按省份、年份、选科与位次建立独立数据源。


## v0.3：院校生态系统

学校现在不再只是属性加成，而会改变实际玩法：

- 6 类培养生态：科研密集型、顶级临床平台型、交叉创新型、强势医科大学型、区域临床强校型、逆风成长型
- 32 所学校均有独立的专属开局事件
- 每类学校有不同的机会事件池与触发概率
- 主线节点会出现不同的院校专属选项
- 入学时生成 6 项个人天赋：记忆力、抗压、沟通、动手、科研直觉、英语
- 天赋会参与后续成功概率和条件判定
- 高资源学校拥有更多机会，但同时承担更高竞争与压力
- 区域/地方院校拥有资源争取、基层实践、考研跃迁等不同路线

培养生态均为游戏化抽象，不代表现实高校官方培养方案或价值排名。

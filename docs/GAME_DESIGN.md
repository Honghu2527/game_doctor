# 游戏设计草案

## 核心体验

《医学生养成记录》不是单纯的“升级打怪”，而是一款以中国医学教育与医生职业路径为背景的分支人生模拟器。

玩家不断在以下资源之间做取舍：

- 知识：考试、临床能力、专业积累
- 体力：值班、学习、科研的生理成本
- 心理：压力、成就感、家庭与职业边界
- 金钱：学生阶段与职业早期的现实资源
- 科研：论文、课题、基金与学术路线
- 声望：患者口碑、同事认可、团队与晋升

## 第一阶段：本科五年

计划扩展为 80–150 个事件，包含：

- 录取与宣誓
- 解剖、生理、生化、病理、药理
- 四六级、奖学金、挂科
- 学生会 / 社团 / 恋爱 / 假期
- 进实验室、保研准备
- 临床见习、实习、第一次抢救
- 考研、保研、直接就业分流

## 第二阶段：研究生 / 博士

- 学硕 / 专硕
- 导师类型与课题组氛围
- 第一篇 SCI
- 阴性结果、拒稿、返修
- 博士申请、毕业压力
- 科研诚信与署名冲突

## 第三阶段：规培 / 住院医师

- 夜班、急诊、轮转
- 医患沟通
- 规培结业与执业资格
- 科室选择
- 收入、租房、家庭关系
- burnout 风险

## 第四阶段：主治到高级职称

- 主治考试
- 临床量、教学、科研三线考核
- 青年基金 / 面上项目
- 副高 / 正高
- 公立 / 私立 / 跳槽
- 科主任 / 学科带头人
- 临床专家 / 学术路线

## 难度设计

### 温和模式
适合体验剧情。资源较高，负面事件惩罚降低。

### 真实模式
默认模式。需要在职业、健康、科研和生活之间持续权衡。

### 地狱模式
初始资源更少，负面消耗更大，burnout 风险显著提高。

## 事件模型

每个事件至少包含：

- stage：人生阶段
- year：年龄 / 年级
- title：事件标题
- text：剧情正文
- choices：选择
- effects：属性变化
- flags：隐藏人生经历
- requires：选项前置条件
- chance：概率结果
- next：下一个事件

隐藏 Flag 用于让早年的选择在多年后产生后果。

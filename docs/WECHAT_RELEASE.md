# 微信小程序上线包（wechat-miniapp 分支）

此分支把现有 HTML/CSS/JavaScript 游戏通过腾讯 Kbone 适配为微信小程序，不改变 main 分支网页版。

## 你只需要补 2 个账号值

1. **小程序 AppID**：微信公众平台后台可见。
2. **激励视频广告位 ID**：开通流量主并创建激励视频广告位后得到 `adunit-...`。如果暂时没有广告位，保持为空即可；正式小程序中不会发放“模拟广告奖励”。

广告位填写位置：`wechat-src/wechat.config.js`。

## 构建

Windows PowerShell：

```powershell
$env:WECHAT_APPID="wx你的AppID"
npm install --legacy-peer-deps
npm run build:mp
```

构建完成后，小程序项目目录是：

```
dist/mp
```

打开“微信开发者工具” → 导入项目 → 选择 `dist/mp` → 确认 AppID → 真机预览。

## 上传和发布

开发者工具右上角 **上传** → 填版本号（建议首版 `1.0.0`）和备注 → 微信公众平台后台 **版本管理** → 将开发版本提交审核 → 审核通过后发布。

## 提审前后台事项

- 完成小程序主体/管理员配置。
- 选择与内容匹配的服务类目（本项目本质是人生模拟/互动游戏内容；以后台实际可选类目为准）。
- 完成小程序备案。
- 填写隐私保护指引；若首版不采集手机号、定位、通讯录等权限，应按真实功能如实声明。
- 如启用社区留言墙，必须先做云端内容安全、举报、审核与用户内容治理；当前首版建议继续使用本地演示数据，不开放公共 UGC。
- 提审版已开启 `reviewSafe: true`：不允许“分享换复活”；普通分享不发奖励。
- 激励视频只用于资源补给/一次复活，不介入考研、申博、求职等竞争结果。

## 目录说明

- `wechat-src/body.html`：由当前 index.html 的 body 迁移而来。
- `wechat-src/index.mp.js`：小程序 Kbone 入口。
- `wechat-src/wechat.config.js`：广告与审核模式配置。
- `build/`：小程序构建配置。
- `dist/mp`：执行构建后生成，直接导入微信开发者工具。
